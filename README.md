# Stream Cipher Encryption and CRC Error Detection (Grain-128A) — Verilog HDL

An end-to-end secure communication system implemented in Verilog HDL, combining **Grain-128A stream cipher encryption** with **CRC-based error detection** across a sender–channel–receiver architecture.

## Overview

The system models a complete secure communication pipeline:

1. **Sender** — encrypts outgoing data using a keystream generated by the Grain-128A stream cipher and appends a CRC for error detection
2. **Channel** — models the transmission medium between sender and receiver
3. **Receiver** — decrypts incoming data using the synchronized keystream and verifies integrity via CRC check

Design and verification were carried out through RTL simulation and waveform analysis, followed by synthesis to evaluate area, power, and timing — achieving a **maximum operating frequency of 1.28 GHz**.

Simulated using **Icarus Verilog** and analyzed via waveform inspection. Example (top-level testbench):

